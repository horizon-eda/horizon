# Contributing to Horizon EDA

Since Horizon EDA is for the most part a one-person show run by
[me](https://github.com/carrotIndustries/), contributions that fix bugs,
add features or improve usability are always welcome. Due to the 
one-person thing however, my time to work on this project and review 
PRs is fairly limited.

## Use of large language models / generative "AI"

Horizon EDA is the embodiment of how I think a CAD application
for printed circuit board design should be put together. Receiving pull requests where the 
contributor shares the same vision is one of the best things about 
developing Horizon EDA.

Receiving a PR that has non-trivial parts of it generated by an LLM or is
entirely AI-generated however takes the joy out this and makes
reviewing the PR feel like a wasted effort. If you didn't bother writing and
thinking about it, I won't bother reading it.

Therefore, LLM-generated pull requests or PRs containing non-trivial
code written by an LLM will not be accepted in this project.
